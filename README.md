# Power BI Formatting Task

## Project Overview

This project is a **Power BI Formatting Task** designed to demonstrate the use of Power BI formatting features to create a clean, professional, and visually appealing report.

The main focus of this project is on improving the **visual appearance, layout, consistency, and readability** of a Power BI report using different formatting options.

## Objectives

The objectives of this project are:

* To understand Power BI report formatting.
* To create a clean and professional dashboard layout.
* To apply suitable colors, fonts, and backgrounds.
* To format charts, tables, cards, and other visuals.
* To maintain consistency across different visuals.
* To improve dashboard readability and user experience.
* To organize report elements properly on the canvas.

## Tools Used

* **Microsoft Power BI Desktop**
* Power BI Report (.pbix)
